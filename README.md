# Astral Party 칩 선택 가이드

PvE에서 레벨업 칩 선택 창이 뜨면, 각 칩 카드 옆에 **지금 상황에 맞는 추천 배지**를 보여 주는 BepInEx 모드입니다.

## 기능

- 칩마다 ★ 코어 / ○ 무난 / × 비추 배지를 칩 아이콘 오른쪽에 붙입니다. 카드 애니메이션을 따라 움직이고, 규칙이 없는 칩에는 붙지 않습니다.
- 배지에 마우스를 올리면 **왜 그런 판정인지** 이유가 나옵니다. 다른 규칙의 이유도 `참고`로 함께 보입니다.
- 내 캐릭터, 이미 가진 칩, 아군 캐릭터, 맵을 반영해서 판정합니다. 예: 아군에 회복 서포터가 있으면 아드레날린은 비추천.
- 키워드(회복·별빛·표식·에너지) 칩은 두 종류를 고르면 나머지 두 종류가 그 판에서 더 나오지 않습니다. 키워드를 한 종류만 가졌을 때 다른 키워드 칩이 나오면 ※ 표시로 알려 주고, 그 선택으로 막히는 내 캐릭터의 코어 칩도 함께 보여 줍니다. 칩 선택 창 왼쪽 위 패널에는 키워드 4종이 보유(●)·열림(○)·막힘(×, 회색)으로 표시되고, ※ 카드에 마우스를 올리면 고르면 막힐 키워드가 주황색으로 미리 보입니다.
- 낮은 등급이 나오면 "보라 이상 권장"처럼 알려 줍니다.
- 추천 규칙은 `rules.json`에 있어 누구나 고칠 수 있고, 게임을 켠 채 저장하면 몇 초 안에 반영됩니다.
- 게임의 원래 추천 표시는 그대로 두며, 게임 안에서는 외부 통신이 없습니다. 새 버전 확인은 게임 밖 프로그램이 따로 합니다(아래 참고).

## 설치

1. BepInEx 6 IL2CPP가 설치된 Astral Party INT 클라이언트를 준비합니다.
2. ZIP을 게임의 `BepInEx\plugins\` 안에 풉니다. `BepInEx\plugins\AstralPartyChipGuide\` 폴더가 생겨야 합니다.
3. 게임을 켜고 로비에 들어가면 같은 폴더에 `names.json`이 자동으로 만들어집니다. 게임 업데이트나 언어 변경도 다음 실행 때 자동으로 반영됩니다.
4. PvE에서 레벨업 칩 선택 창을 열면 배지가 나옵니다.

PvE에서만 동작합니다. PvP와 관전·리플레이에서는 표시하지 않습니다.

## 설정

첫 실행 뒤 `BepInEx\config\`에 생기는 설정 파일에서 바꿉니다.

| 항목 | 기본값 | 설명 |
|---|---|---|
| 일반 > 활성화 | 켬 | 배지 표시 켜기·끄기 |
| 일반 > 키워드 패널 | 켬 | 칩 선택 창 왼쪽 위에 키워드 4종의 보유·막힘 상태 표시 |
| 일반 > 키워드 고정 경고 | 켬 | 두 번째 키워드를 고르기 전에 나머지 키워드가 막힌다고 알림 |
| 일반 > 템플릿 생성 키 | F10 | `names.json`을 직접 다시 만들 때 사용(평소엔 자동) |
| 진단 > 상세 로그 | 끔 | 칩 창이 열릴 때 읽은 값을 로그에 남김. 문제 보고용 |
| 업데이트 > 새 버전 확인 | 켬 | 게임을 켤 때 새 버전을 확인. 새 버전이 있을 때만 게임 밖에 알림 창이 뜨고, 내려받거나 설치하지는 않음 |

## 새 버전 확인

**게임을 켤 때 새 버전을 확인합니다.** 플러그인 폴더의 `AstralPartyChipGuideUpdater.exe`가 게임 밖에서 GitHub(`raw.githubusercontent.com`)에 요청 하나를 보내며, 계정·게임 정보는 싣지 않습니다. 새 버전이 있을 때만 알림 창이 뜨고 `업데이트하러 가기`(릴리스 페이지 열기)와 `이번 버전은 무시` 중에 고를 수 있습니다. 내려받거나 설치하지는 않습니다. 게임을 켜지 않고 확인하려면 그 exe를 직접 실행하세요. 설정의 `업데이트 > 새 버전 확인`을 끄면 자동 확인을 하지 않습니다.

## 규칙 수정

`rules.json`을 텍스트 편집기로 열어 고칩니다. 캐릭터별 추천, 맵·아군·보유 칩 조건, 이유 문구를 쓰는 법은 [docs/RULES.md](docs/RULES.md)에 있습니다. 문법 오류가 있으면 직전 정상 규칙이 유지되고 로그에 위치가 남습니다.

배지가 어떤 근거와 순서로 정해지는지는 [docs/RECOMMENDATION.md](docs/RECOMMENDATION.md)에 공개해 두었습니다. 틀린 판정이나 빠진 조합을 발견하면 [이슈](https://github.com/YoungHoon02/astral-party-chip-guide/issues)로 알려 주세요.

개발자용 구조 설명은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)를 보세요.

## 출처와 감사

- 기본 추천 데이터: Feiz님의 [「캐릭터별 나왔을 때 집어가면 좋을 코어 칩 및 플레이 방법 가이드」](https://arca.live/b/astralparty/171581722). 작성자의 허락을 받아 사용했습니다. 공략에 없는 일부 조합은 칩 설명과 캐릭터 스킬로 추정했으며 이유 문구가 `추정:`으로 시작합니다.
- 캐릭터 스킬 대조: [Astral Party 커뮤니티 위키](https://astralparty.miraheze.org/wiki/Characters).

## v0.1.0

첫 릴리스입니다.

- PvE 칩 선택 창에서 칩마다 ★ 코어 / ○ 무난 / × 비추 배지를 붙이고, 마우스를 올리면 이유를 보여 줍니다.
- 내 캐릭터, 가진 칩, 아군, 맵에 따라 판정이 달라집니다. 캐릭터 35명의 추천은 Feiz님 공략(허락 받음)을 바탕으로 했고, 공략에 없는 조합은 칩 설명과 캐릭터 스킬로 추정해 보탰습니다.
- 키워드 칩을 한 종류만 가졌을 때 다른 키워드 칩이 나오면 ※ 표시로, 고르면 나머지 두 키워드와 내 캐릭터의 코어 칩이 더 나오지 않는다고 알려 줍니다.
- `rules.json`을 고치면 게임을 켠 채 몇 초 안에 반영되고, 파일이 깨져도 직전 규칙을 유지합니다.
- 게임을 켤 때 새 버전이 있으면 게임 밖 창으로 알려 줍니다.
